# Misfit Audit — what doesn't fit the rest of Godwake

**Date:** 2026-05-31 · **Lane:** `feat/audit-misfit` · **Mode:** READ-ONLY report (no `src/` changes).

## Scope & method

Hunt for content that contradicts the rest of the game: non-positional-engine leftovers,
5e-isms with no engine weight, contradictory mechanics, tone/naming inconsistency, duplicates,
and difficulty/economy outliers. "Fit" is judged against **this game's** established conventions
(non-positional turn engine, 8-bit-dark BG2 setting, the locked design decisions and the rename
map), not tabletop D&D.

Each finding cites the engine evidence for the "fits?" call: what the engine *simulates* vs. what
the content *assumes*. The engine baseline used throughout:

- **No positioning.** `turnOrder` is deterministic (player first, then monsters in spawn order);
  there is no map, no distance, no movement. AoE spells hit *every* live enemy regardless of
  declared shape (`burningHands.ts`, `fireball.ts`, `lightningBolt.ts` all iterate `aliveMonsters`).
- **No initiative** (removed #114; `persistMigration.ts:108`).
- **No attunement** (cap + slots removed #214/v11; `persistMigration.ts:116-118`).
- **Conditions honored:** only `poisoned / frightened / blinded / restrained / weakened / paralyzed`
  have mechanical effect (`playerConditions.ts:66-89`, `holdPerson.ts`).
- **Temp HP is take-the-max, never stacks** (`createCombat.ts:221-230`) — consistent.

## Top findings (most jarring first)

1. **Antagonist renamed to "Velnaris" but his prison and city are still BG2-direct.** The villain is
   "Velnaris" to the player, yet his own taunts say *"Spellhold sealed me once"* and *"Athkatla
   bleeds gold"*, Chapter II is titled "Athkatla", the companion is "Imoen", the faction is "Cowled
   Wizards". One IP name scrubbed, a dozen left raw. (#T1)
2. **The movement/speed system is fully inert** — `movementRemaining` is set from `speed` at every
   combat start and never read by anything. Root of the SPD symptom the team keeps chasing. (#E1)
3. **Inert positional stats are shown to the player as if they were real** — weapon `Range … ft`,
   monster `reach/range/Speed ft`, spell `range` ("100 ft line", "Self (15-ft cone)"). The engine
   has no distance, so these are fake tactical info. Directly the trust-erosion pattern in
   `feedback-only-dnd-rules-that-fit`. (#E2, #E3)
4. **Dead 5e item stats in the tooltip** — `Weight`, `Stealth: disadvantage`, `Str req`, and a dead
   `Soul-bound` row, none of which the engine reads. (#F1, #F2, #F3)
5. **The blessing pool is padded with reskins** — six effects are cloned across gods (3× +1 AC, 2×
   crit-range, 2× first-attack-advantage, 2× +1 radiant, 2× +1 damage, 2× stabilise); a
   category de-dup at offer time is a band-aid over the redundancy. (#D1)

## Verified clean (checked — no action; recorded so future lanes don't re-investigate)

- **Temp HP stacking** — consistent RAW take-the-max across every source (blessings, affix, legendary,
  boss-intel gird). `createCombat.ts:221-230,272-274`.
- **Flavor-only quirks** — all six (`sun-touched`, `bardic-memory`, `silver-tongue`, `plain-face`,
  `cold-touched`, `beast-marked`) are `enabled: false` and filtered from the reincarnation roll
  (`quirks/index.ts:262-264`). The no-flavor-only rule holds; they're retained only for save-compat.
- **Legendary system** — a single pipeline: relic effects + set bonuses fold into the shared
  `AffixModifiers` channels (`legendaries.ts:158-166`, `affixMods.ts:114-120`); the old
  `legendaryBonuses` stat path is stripped in v11 migration. No dual system remains.
- **Class features** — every kit feature is honored; `sneak-attack` / `uncanny-dodge` / `fast-hands`
  are detected by class+level rather than a `mechanicKey` lookup (`playerAttack.ts:380`,
  `damage.ts:79`, `cunningAction.ts:31`), which is why a mechanicKey grep shows zero — not dead.
- **`firstStrikeAdvantage`** (boss intel) — honored as "advantage on opening strike"
  (`createCombat.ts:266`); the name echoes the removed initiative system but the effect is real.
- **Wizard blessing/camp gating** — the bulk of the attack-roll-lever cleanup (#113) is in place;
  only the two residuals in I1 leak through.

## Notes on severity

- **JARRING** — none rise to "a player will immediately see this is broken." T1 is the closest
  for a BG2-literate player.
- **INCONSISTENT** — contradicts an established convention or shows the player something untrue
  (T1, E1, E2, D1).
- **MINOR** — dead field / cosmetic / low-visibility (E3, E4, F1-F4, I1, D2, O1).
- **SETTING-FIT** — a deliberate adaptation that reads slightly off but is defensible (I2).
