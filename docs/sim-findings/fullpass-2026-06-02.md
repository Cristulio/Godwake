# Full all-class sim pass — anomaly hunt (2026-06-02)

Branch `feat/sim-fullpass`. Measurement + anomaly hunt on current `main`
(@ 0bb8a53). Since the last full sim (#301) only audiovisual + bug fixes
shipped — no balance/content changes — so the balance magnitudes overlap #301.
This pass is the definitive CURRENT picture plus an active hunt for things that
are inconsistent or off. **No engine/content/balance was changed**;
instrumentation was added to the sim scripts to count the #299 maneuvers and
Nimble Dodge, then reverted.

## Matrix run

- `sim-class-viability` × 3 archetypes (cautious/balanced/aggressive), ascension
  climbs internally A0→A6, `SOULS_PER_CLASS=30 MAX_LIVES=35`.
- `sim-feel` × 3 archetypes × ascension {0, 3, 6}, `RUNS=15`, default
  `LEVELS=1,3,5,7`.
- `sim-xp-curve` × 1 (4000 routed delves).

Reduced-N vs the full defaults (150×150 / RUNS=40) so the whole matrix finishes
in seconds; the relative reads are stable, the magnitudes are noisier than a full
run (twist cells are ~100 fights each — treat twist win-rate deltas as soft).

> **AI-FLOOR CAVEAT (applies to everything below).** The shared Auto-Battle bot
> underplays a real player, so absolute clear-rates (0% across the board here)
> and life-counts are an AI-floor artifact, not game truth. The user has cleared
> the whole game by hand. Every read below is RELATIVE (class-vs-class,
> chapter-vs-neighbor, ascension-vs-ascension). Endgame balance is a PLAYTEST
> question, not a sim one — no fixes/numbers proposed here.

## Prioritized "inconsistencies / things off"

Ranked: likely-bug > balance-out-of-band > difficulty-outlier > minor. Each tagged
NEW vs the known-provisional set (the #301/#286/#300 findings in memory).

### Likely-bug
**None.** No class threw, NaN'd, hit the round/turn cap, stuck in a degenerate
loop, or failed to progress beyond chapter 1 for a structural reason. All 12
matrix cells exited clean; no error/NaN/Infinity in any log. Every signature
ability fires (proc table below) — no ~0 proc that would signal an unwired kit.

### Balance — out of (the asymmetric) band
The class philosophy is explicitly NOT flat-balanced, so "out of band" means a
*relative* surprise, not an absolute number.

1. **[KNOWN] Barbarian is the lone, large high-side.** Deepest per-life in all
   three archetypes by a wide margin (depth 10.0–11.3 vs the next class 7.9–9.3).
   Confirms the parked "Barb > Fighter (post-maneuvers), awaiting playtest" flag —
   and it is not marginal, Barb leads the field by ~25–60%. Watch-the-high-side
   candidate for the eventual tune.
2. **[KNOWN] Rogue is lone-last in all three archetypes** (depth 4.9–5.2). Its
   kit fires fully (Sneak 2.23, Hide 1.36, Nimble Dodge 4.56/combat) — this is
   the genuine bare-soul L1 fragility (#274), not a wiring failure. Nimble Dodge
   (#282) IS firing; it softens but does not erase the floor.
3. **[NEW-ish] Druid sits 5th (below Wizard) at the bare-soul floor** in all
   three archetypes (druid 5.3–6.1 vs wizard 7.1–7.2). The #286 matched-level
   read had Druid *just above* Wizard ("caster hard-tier, 5th"). The order is
   inverted HERE because this is the bare-soul L1 reincarnation chain, not a
   matched-level pull: Wild Shape is L2-gated (procs only 0.45/combat — it
   barely fires before the soul dies), so an L1 druid has no defensive identity
   and a thinner L1 spell list than the wizard. Read as the same L1-floor story
   as Rogue/Ranger, surfacing in a different lens — not a regression, but worth
   a note since it flips the caster-pair order. (sim-feel does not include Druid,
   so this is the only lens on it.)
4. **[KNOWN] Depth ≠ clears: Barbarian goes deepest but Fighter is the only
   class that ever closes A0.** Fighter is the sole class to clear A0 in this
   matrix (balanced 10%, aggressive 13.3% of souls; Barb just 3.3% balanced,
   0% elsewhere) despite Fighter being only 2nd–4th on depth. Consistent with
   "Barb deep-but-doesn't-close" (#268). Not off — a texture worth keeping in
   view when reading depth as power.

### Difficulty — outliers
5. **[KNOWN] Asc0 overall blowout ~69–71%** (cautious 70.9 / balanced 69.5 /
   aggressive 68.9). The post-batch ~70% rebound is intact, archetype-invariant.
6. **[KNOWN, sharpened] Ch1–5 are uniformly trivial; Ch6 is a hard cliff.**
   Non-boss blowout sits at ~75–80% for Ch1–5 then craters to **41.8% at Ch6**
   (a0) / **34.3%** (a6), partially recovering Ch7+. This is the sweep artifact
   (#300) seen from the other side: the `LEVELS=1,3,5,7` starts over-level Ch1–5
   and burst lone trash, and Ch6 (boss CR10) is the first chapter the L7 start
   no longer over-levels, so tension snaps back. The discontinuity is a sampling
   boundary, not a Ch6 content spike — but Ch1–5 being a flat trivial plateau is
   the real signal under the aggregate ~70%.
7. **[NEW] Gloom is nearly inert as a twist; the cursed-ground/quickening
   labels have swapped which one is "lethal."** At Asc6 (balanced), twist-norm
   fights average blow 56% vs clean-norm 69% — twists as a bucket add tension,
   good. But within them: **Gloom blow 71.3% / minHP 79.1% is indistinguishable
   from a clean fight** (clean blow 69.1 / minHP 78.3) — the first-attack
   disadvantage barely registers for the bot, so Gloom is close to a no-op. And
   the known "**Cursed Ground = lone win-rate dropper**" does NOT replicate: here
   Cursed Ground is the biggest *tension* add (blow 42–48%, lowest minHP ~64%)
   but its win rate is ~95%, while **Quickening** is the lowest-win twist
   (90.8–93.8%). So the lethal-vs-tense roles read as Quickening=lethal,
   Cursed-Ground=tense, Gloom=inert. Treat the win-rate ordering as soft
   (~100 fights/twist), but Gloom's near-inertness is consistent across all
   three Asc6 cells and is the firmer flag.

### Minor
8. **[OK] Ascension scaling is monotone harder** on every axis: blowout
   69.5→66.9→63.4, meanRooms 42.3→32.3→27.8, meanMinHP 77.4→74.8→73.0 (balanced,
   A0→A3→A6). Elite win-rate falls and elite rounds climb (ascendant elites @≥2);
   boss blowout falls and boss rounds climb (second-wind @≥3). All as designed.
9. **[OK] Leveling is in-band.** L20 lands Ch13 (random routing) / Ch12 (combat
   routing) — inside the Ch12–14 target. XP is class-agnostic, so there is no
   per-class leveling oddity; the low class-viability final levels (1.5–2.9) are
   the bare-soul death wall, not a leveling bug.
10. **[OK] Power Attack fires ~every fighter turn** (3.82/combat ≈ once per the
    ~3.5 rounds it survives) — stance kept up, not a double-fire anomaly.
    Knockdown (0.13) and Wild Shape (0.45) are the lowest non-zero procs, both
    explained by gating (Knockdown rage+resource-gated; Wild Shape L2-gated on a
    soul that mostly dies at L1–2), not by being unwired.

## Net

The current build is structurally sound: no bugs surfaced, every kit fires,
ascension and leveling are monotone/in-band, and the balance picture matches
#301. The genuine flags are all known-and-provisional (Barb high-side, Rogue
low, Fighter cautious-dip, Asc0 ~70% blowout, Ch1–5 trivial plateau) plus two
NEW-ish nuances worth the user's eye at playtest: **Druid drops below Wizard at
the bare-soul L1 floor** (caster-pair order flip vs the #286 matched-level read),
and **Gloom is nearly inert as a twist while Quickening — not Cursed Ground — is
the lethal one** this run. Nothing here warrants a code change ahead of the
sound-on playtest; this pass exists to flag, precisely, what to watch.
